## 第一节课：Vibe Coding 基础认知（Jason）

1) MVP 场景描述（真实可落地）
- 目标受众：小宇宙 500–2000 订阅量播客（长青类、商业类）
- 主要痛点：节目分发到处是链接，缺统一“名片”；节目文稿/摘要手工耗时；缺可追踪的 CTA（订阅、商务合作、赞助）
- 解决方案：
  - 落地页聚合：自动拉取 RSS 节目，生成摘要、亮点与关键词
  - 自定义主题：可选风格与品牌色；社媒链接聚合
  - 明确 CTA：订阅渠道、赞助方式、商务邮箱/表单；基础埋点追踪
- 成功指标（首周）：
  - 站点访问 UV ≥ 100；CTA 点击率 ≥ 5%
  - 站点搭建与更新人力 < 2 小时/周

2) 工作流设计（Vibe 优化点）
- 需求验证：与 3 位播客主通话 15 分钟，明确“展示-转化”路径与最低付费点
- 规格产出：VibeSpecs 列出页面区域、数据源（RSS/手填）、摘要规则、埋点与数据看板
- 自动化链路：
  - 抓取：RSS → 规范化 JSON（标题/时长/时间/链接）
  - 生成：LLM 摘要/亮点/标签（可控温度；敏感词规避）
  - 展示：Next.js（ISR）+ Tailwind；可静态导出
  - 部署：Vercel；域名解析；加 OG 图
  - 数据：简单埋点（pageview、cta_click）；每周复盘迭代
