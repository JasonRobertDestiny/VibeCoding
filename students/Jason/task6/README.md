## 第六节课：独立站如何付费转化（深化）

交付物（Jason）
- 站点原型：针对目标播客的个性化展示页（静态 Demo + 文案）
- 运营动作：外联话术、反馈记录、价格与交付边界
- 数据记录：访问与 CTA 指标的采集方案（占位）

1) 站点原型（静态 Demo）
- 位置：`site/index.html`（本目录）
- 目标：用于 500–2000 订阅播客的品牌统一页，突出节目亮点与 CTA

2) 外联与转化话术（示例）
- 微信/私信开场：
  - “我为播客主做了一个可复用的展示页模板，能自动抓取节目并生成亮点摘要。可选品牌色与社媒聚合，一页完成订阅与合作。可以帮你搭一个试试看吗？支持自定义域名与数据看板。”
- 明确价值：
  - “目标是一周省 5 小时更新；订阅与商务 CTA 可追踪，方便评估赞助与转化。”
- 付费边界：
  - “试用免费，正式版 99–199/月，含基础运维与每周摘要更新。”

3) 数据与埋点（占位）
- 方案：通过 Vercel + 简单埋点（pageview、cta_click），每周导出 CSV 复盘
- 指标：UV、CTA 点击率、分享次数

4) 下一步计划
- 将 Demo 接入 RSS 实数据，生成摘要后端或批处理脚本
- 引入自定义域名与 OG 图自动化
